# Relief 要件定義

## 目的

- アトピー肌状態を日次で記録し、食事・水分・症状を可視化する
- AIによる糖質・塩分推定と日次アドバイスでセルフケアを支援する
- アトピービジネスに惑わされず、多額のお金や外用ステロイドを使わずに、自分でコントロールできるようにほしい思い。

## ゴール

- デイリーで肌の状態をセルフケアすることで自身の生活を振り返ることにより、肌のコントロールができるようにする
- 肌のコントロールをすることで自然に肌の回復するための補助的なツールとして使用される

## 対象ユーザー

- アトピー性皮膚炎の人向けで、かゆみや肌トラブルを日々記録し、傾向を把握したいユーザー。

# 参考とするデータ

- 本アプリは以下の療法を取り入れたものとする
  - 脱保湿療法
  - 脱ステロイド療法
  - 糖質制限によるヒスタミンの抑止
  - 水分制限、運動による療法

## 制約事項

- 参考とするデータをもとにアプリは作られているが、セルフケア(ウェルネスアプリ)を目的とするため、医療的な診断は行わないこと。
- 日次アドバイス、相談チャットも医療的な行為は禁止。
- 注意文言として、主治医や皮膚i科へ相談する旨を追加すること。 

## 機能要件

- 日付を選択して当日の記録を入力・編集できること
- 日付はカレンダー機能で指定できること。今日の日付を指定できること
- ダッシュボードでの表示と各種入力機能を分けたUIとする
- かゆみスコア、水分量、メモ(肌の状態等で気づいたこと)、食事内容を記録できること
- 水分制限をするなどといった指示も出さないこと。
- 食事内容から糖質・塩分の推定値を表示できること,有料コンテンツとし回数制限をもうけること
- 推定値はユーザーが上書きできること
- 日次アドバイスを生成できること、またこれは有料コンテンツとし、回数制限をもうけること
- 相談チャットで簡易応答ができること。これは有料コンテンツとし、回数制限を儲けること
- サブスクの実装を想定。無料での利用は14日間記録し、それ以前は削除する

## 非機能要件

- モバイルファーストで見やすいUIであること。
- モバイルアプリ内に記録すること
- 記録は3年分とし、バックアップは有料課金とする
- 画面操作が軽快で、入力が簡単であること

# Relief 仕様書

## 概要
アトピー肌状態を記録し、AIで糖質・塩分推定と日次アドバイスを行うセルフケア支援アプリ
記録はセッション内のメモリのみで永続化は行いません。

## 主要機能
- 日次記録の入力（かゆみの強さ、1日の合計水分量、メモ(その日の症状等)、食事内容）
- 過去の入力を確認(カレンダーで指定) 1ヶ月まで(それ以上は有料コンテンツにする)
- 有料コンテンツ：食事内容から糖質・塩分を推定（AIで生成）
- 有料コンテンツ；日次アドバイス生成（AIで生成）
- 有料コンテンツ:相談チャット（AIはスタブ応答）

## 画面構成

- ヘッダー（ブランド/説明/チップ）
- カレンダー（前日/翌日ボタン + カレンダーを表示し指定日を選択する）
- ダッシュボード
  以下をタブで切り替えるようにする
  - 今日のまとめ（かゆみ/水分/運動）今日のまとめの表示部分をクリックすると入力グリッドへ切り替えるようにする。
  - 入力グリッド（かゆみ/水分/症状、 食事入力 + 栄養(手動入力もできるように) + AI推定ボタン
- 有料：日次アドバイス
- 有料：相談チャット

## 入力項目
以下の順にする
- 水分
  - その日の水分合計（ml）
  - こまめに水分を取るために追加する方式とする。入力は時間,摂取水分量とする。これはログとしてDBに保存する
  - 時間は現在時刻とする。また修正できるようにする。
  - 時刻順に自動的にソートすること
  - 水分の指定は「任意入力」「+50ml」 「+100ml」 「+150ml」とする
  - １日の最大摂取水分を設定ができるようにする。グラフで表すようにする。
- 運動(何時間)
  - ウォーキング 00km
  - ランニング  00km
- 食事内容（自由記述）
  - 栄養の糖質/塩分の入力(AIで推定した場合は自動入力)
  - AIで糖質/塩分を推定するボタン
- かゆみ
  - かゆみの部位（任意）
  - かゆみスコア（0–10）
- メモ（任意）

## 技術スタック

- 言語: React/NextJS/TypeScript
- DB:supabase(PostgreSQL)

## データモデル

- DayRecord
  - itch_area: Optional[str]
  - itch_score: int
  - note: Optional[str]
  - water_ml: int
  - meals_text: str
  - carb_estimated_g: int
  - carb_override_g: Optional[int]
  - salt_estimated_g: float
  - salt_override_g: Optional[float]
  - walking_km: float
  - running_km: float

## AIの推定ロジック

- 糖質/塩分
  - `nutrition.py` でプロンプト生成・AI送信・JSON解析
  - 送信先未設定/失敗時はダミー値にフォールバック
  - 文部科学省公開の成分表を読み込む
- 日次アドバイス
  - `advice.py` でプロンプト生成・AI送信
  - 送信先未設定/失敗時は既定テキストにフォールバック

## AI送信の差し替えポイント(有料)

AIの機能は有料とする。現時点では実装しない。
セッションに関数をセットするとAI送信に切り替わります。

- 栄養推定:
  - 入力値: 食事内容
  - 返り値: JSON文字列(糖質・塩分に反映する)
    - 例: `{"carbs_g": 70, "salt_g": 6.5, "reason": "主食と汁物が多いため"}`
- 日次アドバイス: 
  - 入力値: アドバイスの生成ボタン
  - 返り値: 文字列（アドバイス本文）
- 相談チャット
  - 入力値：チャット文の入力
  - 返り値: 文字列(回答本文)
