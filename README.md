# Relief 要件定義

## 目的
肌状態を日次で記録し、食事・水分・症状を可視化する
- AIによる糖質・塩分推定と日次アドバイスでセルフケアを支援する
- アトピービジネスに惑わされず、多額のお金や外用ステロイドを使わずに上手くコントロールできるようにほしい思い

## 対象ユーザー
- アトピー性皮膚炎の人向けで、かゆみや肌トラブルを日々記録し、傾向を把握したいユーザー。

## 制約事項
- 医療的な診断は行わないこと。セルフケアの参考情報を目的とする。
- 日次アドバイス、相談チャットも医療的な行為は禁止。
- 注意文言として、主治医や皮膚科へ相談する旨を追加すること。 

## 機能要件
- 日付を選択して当日の記録を入力・編集できること
- かゆみスコア、水分量、メモ(肌の状態等で気づいたこと)、食事内容を記録できること
- 食事内容から糖質・塩分の推定値を表示できること
- 推定値はユーザーが上書きできること
- 日次アドバイスを生成できること
- 相談チャットで簡易応答ができること。
- AI送信が未設定/失敗時はダミー/既定値で動作確認できること
- サブスクの実装を想定。無料での利用は14日間記録し、それ以前は削除する

## 非機能要件
- モバイルファーストで見やすいUIであること。
- セッション内メモリのみで動作し、永続化しないこと
- 画面操作が軽快で、入力が簡単であること
  

# Relief 仕様書

## 概要
肌の状態を記録し、AIで糖質・塩分推定と日次アドバイスを行うセルフケア支援アプリ（Streamlit）。
記録はセッション内のメモリのみで永続化は行いません。

## 主要機能
- 日次記録の入力（かゆみ、水分、メモ(その日の症状等)、食事内容）
- 食事内容から糖質・塩分を推定（AI送信 or ダミー）
- 日次アドバイス生成（AI送信 or ダミー）
- 相談チャット（AIはスタブ応答）
- 過去日の閲覧・編集（カレンダーで日付切替）

## 画面構成
- ヘッダー（ブランド/説明/チップ）
- カレンダー（前日/翌日ボタン + 日付入力）
- ダッシュボード
  - 状態サマリー（かゆみ/水分/糖質/塩分）
  - 入力グリッド（かゆみ/水分/症状）
  - 食事入力 + 推定ボタン + 上書き
  - 日次アドバイス
- 相談チャット

## 入力項目
- かゆみ
  - かゆみの部位（任意）
  - かゆみスコア（0–10）
- 水分
  - その日の水分合計（ml）
- メモ（任意）
- 食事内容（自由記述）
- 糖質/塩分の上書き（任意）

## データモデル
- DayRecord
  - itch_area: str
  - itch_score: int
  - symptoms: List[str]
  - note: str
  - water_ml: int
  - meals_text: str
  - carb_estimated_g: int
  - carb_override_g: Optional[int]
  - salt_estimated_g: float
  - salt_override_g: Optional[float]

## 推定ロジック
- 糖質/塩分
  - `nutrition.py` でプロンプト生成・AI送信・JSON解析
  - 送信先未設定/失敗時はダミー値にフォールバック
- 日次アドバイス
  - `advice.py` でプロンプト生成・AI送信
  - 送信先未設定/失敗時は既定テキストにフォールバック

## AI送信の差し替えポイント
セッションに関数をセットするとAI送信に切り替わります。

- 栄養推定: `st.session_state.nutrition_ai_sender`
  - 引数: `prompt: str`
  - 返り値: JSON文字列
    - 例: `{"carbs_g": 70, "salt_g": 6.5, "reason": "主食と汁物が多いため"}`
- 日次アドバイス: `st.session_state.advice_ai_sender`
  - 引数: `prompt: str`
  - 返り値: 文字列（アドバイス本文）

## ダミーAI
デフォルトでは動作確認用のダミーAI送信関数が登録されています。
- 栄養推定: 固定値（糖質 68g / 塩分 6.2g）
- 日次アドバイス: 固定の短文

## 状態管理
すべて `st.session_state` で保持され、リロードで初期化されます。
- records（DayRecord辞書）
- selected_day
- chat
- analysis_days
- advice_text
- max_chat_render
- nutrition_ai_sender / advice_ai_sender

## 画面スタイル
- モバイルファースト
- 優しい明るい配色のカラートークン
- 入力グリッドはモバイルでも横並び
- カレンダーはスマホでも横並びを維持

## 実行方法
```bash
streamlit run app.py
```
